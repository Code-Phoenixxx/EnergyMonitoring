# Project Rules

- Follow `docs/PROJECT_BRIEF.md` as the source of truth. Do not change the stack.
- Work one phase at a time. Stop at the end of each phase and wait for my go-ahead.
- All thresholds, tariffs, machine specs live in `config/*.yaml`. No hardcoded values.
- Add type hints, docstrings and logging. Write pytest tests for detection and cost logic.
- After each phase, give exact commands to run and verify it, and actually run them.
- If something is ambiguous, pick a sensible default, state it in one line, continue.
